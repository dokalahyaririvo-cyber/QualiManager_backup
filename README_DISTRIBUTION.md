# Guide de Distribution - QualiManager v2.1.0

## 🎯 Fichier à Distribuer

**Fichier unique :** `QualiManager_v2.1.0_Setup.exe` (38.2 MB)

**Emplacement :** `output\QualiManager_v2.1.0_Setup.exe`

---

## 📧 Instructions pour vos Utilisateurs

### Installation

1. **Télécharger** le fichier `QualiManager_v2.1.0_Setup.exe`
2. **Double-cliquer** sur le fichier
3. **Suivre l'assistant d'installation** (accepter les paramètres par défaut)
4. **Cliquer sur "Terminer"**

### Premier Lancement

1. **Appuyer sur la touche Windows** ou cliquer sur le Menu Démarrer
2. **Taper "QualiManager"**
3. **Cliquer sur l'icône QualiManager**

### Épingler à la Barre des Tâches (Optionnel)

1. **Ouvrir le Menu Démarrer**
2. **Chercher "QualiManager"**
3. **Clic-droit sur l'icône** → **"Épingler à la barre des tâches"**

✅ L'icône et le nom seront corrects !

### Désinstallation

1. **Panneau de configuration** → **Programmes** → **Désinstaller un programme**
2. **Sélectionner "QualiManager"**
3. **Cliquer sur "Désinstaller"**

---

## ⚙️ Configuration Requise

- **Système d'exploitation :** Windows 10/11 (64-bit)
- **Espace disque :** 150 MB minimum
- **Mémoire RAM :** 4 GB recommandé
- **Permissions :** Droits d'administrateur pour l'installation

---

## 🔒 Sécurité

- L'installateur est signé et sûr
- Aucune connexion Internet requise pour fonctionner
- Les données sont stockées localement dans `%APPDATA%\QualiManager`

---

## 📞 Support

En cas de problème :
- Vérifier que Windows est à jour
- Désinstaller puis réinstaller l'application
- Contacter le support technique
